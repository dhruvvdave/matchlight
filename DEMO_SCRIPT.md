# Demo script: 1 min 55 s

**Setup (before recording):** `npm run dev` (or `docker compose up`), open http://localhost:5173 in a 1600×960 window, full screen. Optional: set Azure variables in `.env` for live Azure OpenAI, Translator and Speech. The script works identically offline. Everything on screen is synthetic: fictional clubs and players, no real league marks, no music.

**Recording:** press **★ Demo mode** (or open `/?demo=1`). The demo is scripted and deterministic (seed 1861) and drives itself for about 88 seconds. Captions appear on screen; the voice-over below fits them.

**Tips**

- Re-running the demo gives the same match (deterministic seed), so retakes line up.
- If you record at 1280×720, the layout reflows; 1600×960 matches the screenshots in the docs.
- Turn on _Read commentary aloud_ only if you want TTS in the recording (there is no music anywhere).
